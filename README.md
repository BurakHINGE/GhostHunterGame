# 👻 GhostHunter

Hunt paranormal entities, survive terrifying encounters, and uncover the mysteries hidden within haunted locations.

---

## 📖 About

GhostHunter is a long-term game development project created as a university project and continuously improved beyond its original scope.

Our goal is not only to build a fun horror game but also to create a collaborative community where developers can contribute ideas, report issues, and help improve the project.

---

## ✨ Features

* 👻 Ghost hunting gameplay
* 🏚️ Haunted environments
* 🎮 Interactive gameplay mechanics
* 🔦 Exploration and investigation
* 📈 Continuous updates
